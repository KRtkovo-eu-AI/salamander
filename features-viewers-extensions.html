Feature guide

Viewers and extensions

Inspect more formats and extend Salamander with native plug-ins or multi-language Salamatrix extensions.

Internal Viewer

  • View Unicode text with optional line numbers and a status bar showing line, column, selection, and zoom information.
  • Zoom with Ctrl+mouse wheel or the numeric keypad shortcuts.
  • Log View Mode refreshes growing files automatically and keeps the view at the end.

Prism Text Viewer

  • View source code, configuration files, logs, and markup with syntax highlighting for hundreds of language identifiers.
  • Choose encoding and lexer settings, line numbers, wrapping, whitespace display, and zoom in a native viewer window that follows Salamander dark mode.

WebView2 Render Viewer

  • Render HTML, Markdown, SVG, modern image formats, and PDF in a native viewer window.
  • Viewer controls, persistent settings, zoom, and Salamander dark mode are shared with the modern viewer framework.

PictView native formats, previews, and thumbnails

  • Native decoders cover formats not guaranteed by Windows Imaging Component, including TGA, PCX, Netpbm, SVG, DDS/DX10, XCF, PDN, 3DM, DWG, WMF/EMF, and embedded previews in EPS, AI, PDF, and MOV.
  • STL files can use the installed Explorer 3D preview handler for interactive rotate and zoom.
  • Panels provide STL, CDR, folder, WebP, SVG, and other supported thumbnails. See the format support details.

Salamatrix Extension Framework

  • Build persistent, manifest-backed extensions with commands, context menus, viewers, panel file systems, native UI, settings, localization, icons, and a dedicated Extension Bar.
  • JavaScript, Python, PowerShell, PHP, and Lua runtimes expose a shared capability surface. Explore Salamatrix.

Process Explorer, Hardware Monitor, and Event Viewer

  • Process Explorer lists running processes with CPU, memory, user, termination, executable-location, and properties actions.
  • Hardware Monitor presents CPU, GPU, memory, motherboard, network, storage, sensors, SMART/NVMe information, utilization, and Device Manager actions.
  • Event Viewer browses Windows logs with localized event properties and XML details.

Salamatrix Studio

  • Use the Visual Studio Code extension to create Salamatrix projects, edit manifests, design native dialogs and menus, preview them, and generate runtime code.
  • Explore Salamatrix Studio.

Plug-in and extension catalog

  • Discover, install, and update native plug-ins, runtimes, and extensions together with their declared dependencies.
  • Catalog entries can provide icons and curated capability information.
