Feature guide

Configuration and security

Move configurations safely between installations and understand the trust and capability model for installed components.

Portability

  • Store the configuration in files instead of the Registry and use a portable installation without Registry entries.

Manage configurations

  • Use the welcome dialog to select configuration storage.
  • Import, export, and restore configurations with a guided wizard and choose the target location.

Translations

  • Use the AI-assisted localization workflow to maintain application and plug-in translations with reviewable candidate files.
  • Translation scripts are partially derived from the Sally fork by 0xeb.

Trusted plug-in installation

  • Official automatic installations fail closed unless the package matches the catalog SHA-256 digest and extracted first-party binaries pass Authenticode publisher validation.
  • Plugin Manager discloses curated security capabilities such as network, external-process, and web access before installation.

Digitally signed

  • All distributed binary files, including the installer, are digitally signed.
