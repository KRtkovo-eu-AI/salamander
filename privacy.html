Privacy Policy - Open Salamander: Samandarin

Effective date
July 4, 2026
Application
Open Salamander: Samandarin
Platform
Windows

Summary: Open Salamander: Samandarin is a local desktop file manager. It does not include developer-operated telemetry, analytics, advertising tracking, user accounts, or cloud synchronization. The application works with files, folders, plugins, archives, network locations, and configuration data only as part of the file-management actions initiated by the user.

1. Overview

Open Salamander: Samandarin is a dual-pane file manager for Windows. This Privacy Policy explains how the application accesses, stores, and transmits data during normal use.

2. Personal data collection

Open Salamander: Samandarin does not require a user account and does not intentionally collect, sell, rent, or share personal data with the developer.

The application does not include developer-operated telemetry or analytics. It does not send usage statistics, advertising identifiers, crash reports, personally identifiable information, local file contents, folder listings, credentials, application history, or configuration data to the developer.

3. Local file and folder access

As a file manager, Open Salamander: Samandarin can access files, folders, archives, plugins, portable devices, network locations, and other resources when the user chooses to browse, open, view, copy, move, rename, delete, compare, calculate checksums, extract, archive, or otherwise manage them.

This access is part of the application's primary functionality and is controlled by the user's actions. The developer does not receive the user's files or file metadata through the application.

4. Local data storage

The application may store local configuration data needed for normal operation. This may include settings, window layout, panel state, file-management preferences, plugin settings, bookmarks, command history, paths, and similar application state.

Depending on the selected configuration mode, this data may be stored in:

  • the Windows Registry, or
  • local configuration files when portable or file-based configuration is enabled.

This data remains on the user's device unless the user explicitly copies it, backs it up, synchronizes it, or shares it using another tool or service.

5. Network usage

Open Salamander: Samandarin may use network connections only when the user initiates or enables functionality that requires network access. Examples include:

  • connecting to FTP servers through the FTP Client plugin,
  • browsing network resources or network shares,
  • opening external project, homepage, or download links,
  • checking plugin update catalogs when that feature is used or enabled,
  • downloading files from locations selected by the user.

These network actions are not used by the developer to collect user data. When the user connects to third-party servers or websites, those services may process standard technical information such as IP address, request time, requested URL, or client information according to their own privacy practices.

6. Plugins

Open Salamander: Samandarin supports plugins. Plugins may provide additional functionality such as archive handling, file viewing, FTP access, checksum calculation, portable device browsing, registry browsing, or update checks.

Plugin behavior depends on the specific plugin and the user's actions. Included plugins are expected to process data locally unless the user explicitly uses a feature that connects to a network resource.

7. Third-party services

The application does not integrate with third-party advertising, analytics, or data collection services. It may link to third-party websites or services, such as GitHub project pages, plugin homepages, download pages, FTP servers, or other network resources selected by the user.

Third-party websites and services are governed by their own privacy policies and server logging practices.

8. Crash reports, issue reports, and support

Open Salamander: Samandarin does not automatically send crash reports to the developer.

If the user manually reports an issue, opens a GitHub issue, sends diagnostic information, attaches screenshots, provides logs, or otherwise contacts the developer, the submitted information may be used to investigate and resolve the issue. Users should avoid sending private or sensitive files unless they intentionally choose to share them for troubleshooting.

9. Data sharing

The developer does not sell, rent, or share personal data collected by the application. The application does not operate a developer-controlled cloud service or user account system.

Data may be transmitted only as a result of user-initiated actions involving third-party websites, FTP servers, network shares, plugin update catalogs, or other network resources.

10. Security and user control

Data processed by Open Salamander: Samandarin is primarily handled locally on the user's device. Users control what files, folders, plugins, credentials, network locations, and external links they use with the application.

Users are responsible for protecting their own Windows account, device, files, credentials, backups, and network connections. Local application settings can be removed by uninstalling the application and deleting its configuration data from the Windows Registry or local configuration storage, depending on the configuration mode used.

11. Children's privacy

Open Salamander: Samandarin is a general-purpose desktop file manager and is not directed specifically at children. The application does not knowingly collect personal data from children under 13 years of age.

12. Open source

Open Salamander: Samandarin is open-source software licensed under GPLv2 or later. The source code is available for review at the project repository: https://github.com/KRtkovo-eu-AI/salamander

13. Changes to this Privacy Policy

This Privacy Policy may be updated when application functionality changes. Any changes will be reflected by updating the effective date above and publishing the current version on the project website or repository.

14. Contact

For privacy questions or issue reports related to Open Salamander: Samandarin, please use the GitHub issue tracker: https://github.com/KRtkovo-eu-AI/salamander/issues

This policy describes the behavior of Open Salamander: Samandarin itself. Operating system features, third-party websites, FTP servers, network shares, browser downloads, and other external services are outside the control of the application and may have their own privacy practices.
