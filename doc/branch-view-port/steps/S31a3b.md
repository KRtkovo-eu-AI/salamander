## Změna a zachování kontrol

`branch_operations_contract_tests.py` používá All při CLI spuštění i při importu
přes unittest discovery. Runner předává výslovně `--scope All`. Historické menší
scope volby zůstávají dostupné pro cílenou diagnostiku, běžná registrace je ale
nepoužívá. Stale selektor názvové schránky nově vybírá skutečný diskový blok
CopyFocusedNameToClipboard: Branch View je diskový panel a stejný wide blok
záměrně chrání i běžné diskové panely. Všechny původní assertions o GetItemFullPathW,
UNC převodu, počtu wide clipboard volání a absenci legacy fallbacku zůstávají.

Kontrola PostChangeOnPathNotification po rename je nyní bez podmínky na scope.
Dřívější All tuto jednu assertion vynechával, přestože byla aktivní v menším
scope. Aktivace širšího běhu proto nesmí pouze přepnout CLI parametr.

V `branch_view_contract_tests.py` odstraněn pouze odklad/load_tests filtr.
Unittest nyní standardně spouští i test přesné identity dočasného dialogového
výběru. Tělo testu ani žádná jiná assertion nejsou změněné. Shell retry assertion
zůstává přesně původní: skutečně chybějící guard opravil S31a3a, zde se nepřepisuje
její očekávání. Produkční C++ kód, SDK, providers a Windows nastavení se nemění.
