## Změna

Rychlé Compress/Uncompress/Encrypt/Decrypt nyní procházejí stejným owned
root/tab/generation/selection guardem jako základní Change Attributes.
NTFS controls odpovídají skutečným volume capabilities. Snapshot se kontroluje
před potvrzením i po modal dialogu a plánování; cleanup nedeselectuje jiný tab.
Inicializace atributů/časů je definovaná i pro fast flow, který konstruuje
společný dialog bez předchozího čtení časů. Worker S31b3a4a je beze změny.

PrepareNtfsConfirmation nahrazuje původní fixed MAX_PATH/path scratch.
Použije dynamický wide resource text a CTruncatedString::SetW s přesnou
relativní identitou v Branch, plnou identitou v ordinary. Plural flow používá
stávající lokalizovaný počet souborů/adresářů (200-byte scratch pouze počty,
nikoli cestu). Hlídá count, range, UpDir a current cache identity.
Subject se vloží do existujícího `%s` outer resource, takže zůstane správné
pořadí otázky a kompletního varování. Nepřibývají nelokalizované UI texty.
