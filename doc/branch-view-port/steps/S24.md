# S24 — Bezpečné formátování zpráv

Stav: PLANNED. Rozsah, závislosti a PR hranice jsou návrh z promptu; před převzetím je nutné ověřit je úzkým diffem připnutého donoru a skutečným target kódem. Jména testů níže jsou převzata ze zadání, nikoli potvrzení jejich dostupnosti nebo běhu. Zdrojový prompt: `steps/S24-message-expansion.md` v balíčku určeném v [SOURCE.json](../SOURCE.json).

## Rozsah

Převzít typed placeholder expander a obecné testy, bez nového lokalizačního frameworku. Překlady nesmějí sloužit jako variadický printf formát.

## Plánované předpoklady

Ověřený předchozí checkpoint; zdrojové resource IDs zatím nezavádět uměle. Compressed-size call sites přenést pouze spolu s potřebnou regresí.

## Donor a testy

Konkrétní audit připnutých symbolů a mezer: [BOUNDARIES.md](../BOUNDARIES.md).
Úplný seznam donorových souborů této etapy a sdílených hunks: řádky S24 v
[REUSE.tsv](../REUSE.tsv). Tyto zjištěné hranice upřesňují původní prompt.

- Zdroj: branch_view_text.h a obecné části branch_view_text_tests; donorové překlady použitých zpráv.
- Testy: Obecné branch_view_text_tests; resource-dependent části explicitně DEFERRED do S26.

## Akceptace

Očekávané %I64u/%s, unknown directives jako literál, vložené procento, null, velká čísla a dlouhý Unicode bez truncation.

## Validační brána a PR hranice

Před kódovým commitem: Windows Debug i Release x64 (host, změněné komponenty a tranzitivní závislosti), relevantní native testy a skutečný smoke běžného panelu/operace; společné SDK/hlavičky vyžadují všechny podporované konzumenty. Příkazy a přesnou evidenci SHA/runtime určuje [VALIDATION.md](../VALIDATION.md). Publikační checkpoint navíc vyžaduje čistou podporovanou sestavu a povinnou platformní matici. Nedostupná native/GUI kontrola není PASS; další etapu nezačínat.

Samostatná message utilita: fix(messages): expand typed localized placeholders safely.

V jednom běhu provést jen jednu nejmenší dokončitelnou etapu/podetapu. Dodržet [CONTRACT.md](../CONTRACT.md), aktualizovat REUSE/PROGRESS a evidenci testů; převzatý kód i testy evidovat vůči připnutému DONOR_SHA. Tento dokument neposkytuje oprávnění k push/PR/merge.
