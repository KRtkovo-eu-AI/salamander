## Doložená návaznost a implementace

Actual donor i target PackUniversalUncompress provádějí temp/list přípravu,
TestFreeSpace a PackExecute (čekání/progress/callbacky), potom borrowed
panel->MoveFiles(srcDir,targetDir,tmpDirNameBuf,archiveFileName). Controller guard
na vnějším vstupu neochrání toto vnitřní předání. Implementace přidává pouze
dva optional interní pointer parametry const CFilesActionDiskTarget* sourceSnapshot
a diskTarget, default NULL v pack.h. Forward deklarace helperu už existovala.

contextIsCurrent používá nezměněný shared live-tab snapshot. Supplied source musí
patřit operation panelu; IsCurrent porovná pointer s attached/detached registry
před getters, pak TabId/root/disk kind/scanning/Branch generation/visible side.
Oba contexts se kontrolují při vstupu před temp I/O, znovu po free-space/expansion
před PackExecute a po čekání i hledání vnitřního rootu před posledním MoveFiles.
Invalidace nevolá MoveFiles. Na začátku se jen vrátí FALSE/ERROR_RETRY; později
se odstraní vlastní list a temporary extraction directory (ne source archive),
potom se nastaví ERROR_RETRY, aby cleanup nepřepsal příčinu.

NULL defaults zachovávají stávající callers v CUnpackerConfig::ExecuteUnpacker
i ostatních archive cestách. Tyto callers jsou v tomto checkpointu beze změny
a nové contexts ještě nepředávají. SDK virtual/ABI, plugin/vendor sources,
donor pin, Branch admission a delete-volumes policy se nemění. Jde o interní
integrační adaptaci, nikoli nové capability API nebo generic framework.
