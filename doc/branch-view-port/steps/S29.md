## Skutečné GUI — PASS

Po odemčení plochy proběhlo 16 scénářů v tmavém Debug a 16 ve světlém Release
nad vlastními čtyřmi obrázky na konfiguraci. Stejné basename mají různé rozměry,
Unicode rodiče a jednu cestu delší než MAX_PATH v UTF-16. Výsledky jsou jednotlivě
zapsány v gui-observations.json a svázány s binárkami přes launch JSON.

- Duplicate na stejnou i opačnou stranu a reopen zavřené karty zachovaly správnou
  úplnou identitu a layout. Release navíc měl jiný fokus než explicitní výběr:
  dlouhý modrý obrázek zůstal vybraný, zelený v Unicode adresáři fokusovaný.
- Open Containing Folder otevřel rodiče fokusovaného souboru; historie Back
  obnovila kolekci, fokus, výběr i layout. Release Forward vrátil běžnou složku.
- Obrácené řazení Path a ruční refresh zachovaly identitu mezi stejnými názvy.
  Debug historie s dočasně chybějícím vybraným souborem ani Release refresh
  s chybějícím dlouhým souborem nevybraly jinou stejnojmennou položku.
- Detailed, Icons i Thumbnails zachovaly layout; Debug ověřil i prázdný explicitní
  výběr. Vypnutí Branch View zachovalo layout a vrátilo běžné řazení bez Path.
- Běžné panely fungovaly před i po testech. Po uložení profilu s Branch flagy
  a binárním Unicode fokusem restart bez process-only gate neaktivoval Branch
  View ani přes Back do uložené historie, ani přes Ctrl+B; oba buildy PASS.
