## Zjištění a přesná oprava

Původní S31 diagnóza G03 mylně označila oba errors jako pouhé stale selektory.
U Shell testu jeho assertion správně vyžadovala opětovnou kontrolu
`panel->ContextMenu != NULL && h != NULL` po retry. V portu chyběla oproti donoru
ukončená přípravná větev a nový guard kolem následné práce/menu fallbacku.
Selhání CreatePopupMenu nebo nového COM provideru tak zůstávalo uvnitř původně
platné větve a nedosáhlo host fallbacku. Není vhodné posunout assertion před retry.

V `src/shellsup.cpp::ShellAction`, saContextMenu, obnoven přesný donorový guard
a TRUE quiet argument při retry CreatePanelShellMenu. Příprava a následné použití
mají samostatné kontroly, po neúspěšném retry se zvolí stávající úplný Branch
host menu fallback. Původní cleanup/odložený dispatch mimo Shell se nemění.
Zdroj: připnutý donor `47661e92d4b3cbe5bb593ae3d75a3f1f698ef413`.

Test `test_unsupported_shell_menu_falls_back_to_complete_host_selection` prošel
bez jakékoli změny jeho assertions nebo selektoru. Oba contract test soubory
zůstávají v této etapě beze změny. Clipboard selektor a rozsah All/temp-selection
zůstávají výslovně pro S31a3b; G03 celkově ještě není uzavřen.
