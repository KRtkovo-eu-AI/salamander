## Rozdíl dialogové a drop cesty

DropCopyMove pro Branch před vstupem do práce volá IsRootDropTarget(GetPathW(),
targetPath). Helper zůstal shodný s revizí S31b5a: UTF8-first/ACP decode a přesná
wide textová shoda kořene. Odmítá jiné child/root texty, neprovádí obecné Windows
rozlišení aliasů nebo reparse identity a není transakcí nad filesystémem.

Dialogový FilesAction zachytí úplný root, TabId, Branch generation, typ a případně
viditelnou stranu před modal dispatch. Ruční cíl smí mít vlastní resolver
semantiku; klasifikace nezměněného root\*.* předchází normalizaci. Pro implicitní
cíl musí ParsePath najít existující celý root s jedinou maskou za secondPart;
split/create nesmí ze zkráceného kontextu vytvořit jiný cíl. Po splitu se ověří
obě NUL, mask pointer uvnitř skutečné caller kapacity a plný root. Životnost cíle
se zjišťuje vyhledáním v živém registru před getter přístupy. Nejde o pouhé
odstranění guardu nebo mechanické použití root-only helperu na text s maskou.

Obě cesty zachovávají Name/NameW jako basename a skutečné per-item source cesty.
Exact textový root není OS file-ID kontrola ani ochrana před všemi vnějšími
filesystem závody; nevyvozovat takovou záruku ze snapshotu panelu.

## Zbývající práce

S31b5 uzavírá tyto tři nálezy pro ověřený diskový rozsah. G04/G05 zůstávají OPEN:
UnpackZIPArchive ve fileswn7.cpp stále odmítá Branch source i Branch target;
Pack odmítá Branch target, Unpack také Branch source/target. Jsou to samostatné
callback/resolver cesty, nikoli chyba, kterou lze napravit odstraněním všech
guardů po Copy/Move testu. Další nejmenší etapa S31b6a najde donorové hunks pro
přímé rozbalení a jeho cílový kontext, závislosti a relevantní testy; teprve potom
stanoví malé implementační podetapy. Bez zapnutí neověřených operací.

Long-source GUI/Unpack nadále DEFERRED/NOT_VERIFIED; e1/e2/e3 dlouhé cíle nejsou
důkazem GUI přechodu na dlouhý source. Síť/UNC, cross-volume, EFS, fault injection,
kompletní jazykový staging a čistá supported platformní/plugin matice mají své
G05 hranice. Jejich uzavření není nahrazeno tímto auditem. Žádný nový build,
native ani GUI běh, remote CI/CodeQL v této dokumentační etapě. S32 BLOCKED,
celá S31 neuzavřena, bez push/PR. Dřívější technická GUI blokace byla odstraněna.
