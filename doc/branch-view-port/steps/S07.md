# S07 — Batch Rename

Stav: PLANNED. Rozsah, závislosti a PR hranice jsou návrh z promptu; před převzetím je nutné ověřit je úzkým diffem připnutého donoru a skutečným target kódem. Jména testů níže jsou převzata ze zadání, nikoli potvrzení jejich dostupnosti nebo běhu. Zdrojový prompt: `steps/S07-batch-rename.md` v balíčku určeném v [SOURCE.json](../SOURCE.json).

## Rozsah

Převzít owned vstupy, skutečné per-item rodiče, relative mode, preview, rename a Undo společně; zachovat podporované virtuální režimy.

## Plánované předpoklady

S05 a potřebné wide I/O základy; ověřit životnost snapshotu v modeless UI.

## Donor a testy

Konkrétní audit připnutých symbolů a mezer: [BOUNDARIES.md](../BOUNDARIES.md).
Úplný seznam donorových souborů této etapy a sdílených hunks: řádky S07 v
[REUSE.tsv](../REUSE.tsv). Tyto zjištěné hranice upřesňují původní prompt.

- Zdroj: src/plugins/renamer; renamer_paths.h, renamer_io.h a související projektová registrace.
- Testy: renamer_panel_paths_tests; renamer_io_tests se skutečným dočasným rename I/O.

## Akceptace

Snapshot přežije sort/refresh. Cancel nemění soubory; Undo míří na původní položku, shodné basename nelze zaměnit. Ověřit skutečný výsledek a nezměněné ostatní zdroje.

## Validační brána a PR hranice

Před kódovým commitem: Windows Debug i Release x64 (host, změněné komponenty a tranzitivní závislosti), relevantní native testy a skutečný smoke běžného panelu/operace; společné SDK/hlavičky vyžadují všechny podporované konzumenty.
