## Skutečné výsledky a adaptace

Service class a factory jsou přesný donorový kód; public interface declaration
má pouze dokumentační omezení na ordinary local/UNC. QueryService přidává pouze
built-in větev. Ordinary getters používají stávající SalPathAppendW (včetně
již přítomného forward separatoru), bez nové join implementace. Donorový ACP
fallback opraven na validní UTF8-first/ACP poté, co skutečný harness odhalil
UTF8 root/name bez wide dat. Name/NameW zůstávají basename, synthetic '..'
navigation zachována. SDK Abstract bodies a CFileData layout neměněné.
Nový service/ABI/fault harness vychází z donor ordinary Paths fixtures a
používá již zavedený SafeFile compiler driver. Branch assertions do S26,
owned selection/disk snapshot assertions do S05. Žádné jejich oslabení
nebo tvrzení, že byly v S04 spuštěny. GUI consumer migrace nejsou S04.
