Stav: PLANNED. Rozsah, závislosti a PR hranice jsou návrh z promptu; před převzetím je nutné ověřit je úzkým diffem připnutého donoru a skutečným target kódem. ## Rozsah

Převzít skutečný resolver full/parent/relative path běžného diskového panelu a službu PanelItemPaths. Neimportovat celé fileswn*.cpp ani scanner. Borrowed CFileData nepoužívat za hranicí životnosti.

## Akceptace

Ověřený minimální předkrok uvnitř S04: obyčejné části
`GetItemDirectoryW/GetItemFullPathW/GetItemIdentityW/GetItemRelativePathW`
jsou v donor `branch_view.cpp` a používají `Salamander::BranchView::Join`.
Přenést je do již kompilované host translation unit, jediný join helper,
bez `CBranchViewState`. Zapsat zvolenou cílovou cestu do REUSE. Služba
`CPanelItemPathsService::FindCurrentItem/GetItemFullPath` je v `src/zip.cpp`.
`branch_panel_getters_tests.py` extrahuje i budoucí Branch Entry/state:
ordinary subset má mít minimální adaptovaný harness, Branch assertions až S26.

Invalid/stale pointer, wrong thread, synthetic '..', Unicode, kapacita a explicitní chyby. CFileData.Name/NameW zůstávají basename; layout/ABI i archive/FS virtuální cesty se zachovají.
