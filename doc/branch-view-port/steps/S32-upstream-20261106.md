1. **Unpack target:** resolve the upstream implicit inactive target before taking
   a live disk/Branch target identity. Revalidate after the dialog and callbacks;
   no late fallback bypasses the captured target or source lifetime checks.
2. **Copy/move scheduling:** retain upstream automatic/forced scheduling override
   and drive-aware controls while using owned full-path dialog text. DEFAULT
   remains an automatic policy, not an unconditional parallel request.
3. **Archive cache:** keep upstream size/time invalidation and its `CFileData*`
   signature alongside strict UTF-8/ACP routing and wide Branch source identity.
4. **Plugin shutdown:** retain native-provider preflight/finalization, upstream
   deferred module ownership and the no-CLR-Stop managed path. Refusal must not
   free provider code while a consumer remains active. Retain one loader reference
   per deferred load, including duplicate handles across provider reloads. Reserve
   ownership storage before finalization/Release; low memory refuses teardown.
   Actual-method tests cover repeated refusal/reload, immediate unload, final
   retry and the lost-reference negative control.
5. **Full-path Shell:** apply upstream Shell-extension SEH survival to the port's
   creation and cleanup routes. A failed parse or extension call cannot publish a
   partial selection. Existing `SetData(TRUE)` ownership transfer is retained:
   the real Windows
   data object rejects FALSE with `E_NOTIMPL`. A normal failed HRESULT frees the
   caller-owned medium. After SEH, ownership is unknowable; avoiding a double free
   takes priority over reclaiming a possible fault-only allocation leak. Normal
   success must retain exact CF_HDROP and the preferred drop effect.
6. **Resources:** retain both the Branch/long-path UI and new drive information,
   preference, attribution and regression registrations. Repair 22 missing keep-
   paths checkbox placeholders in the eleven localized Copy/Move dialogs, using
   the existing localized runtime caption and native 14-DLU expansion. Imports
   still require `[EXPORTINFO]` first and their existing encoding/newlines.
7. **Shared SDK and runtimes:** preserve old virtual prefixes, appended services
   and size-tagged viewer fields. New upstream `viewFile` option forwarding must
   agree across all five language providers, including malformed inputs/defaults.
