## Doložený problém a oprava

Audit navazujícího zapojení atributů zjistil, že již existující DoChangeAttrs
ignoruje výsledek GetFileTime a SetFileTime. Po neúspěšném čtení mohl použít
neinicializované FILETIME; po selhání zápisu či obnovy Read-only mohl navýšit
progress a vrátit TRUE. Tuto chybu obsahuje parent před tímto checkpointem.

Stejná finální native sada proti parent workeru projde kompilací, ale skončí
**73 kontrol,12 assertion failures**. Je to funkční reprodukce; první historický
pokus měl compile failure v nové fixture a není použit jako důkaz regresí.
Finální harness opravil typ enum initializeru/castu bez vypínání /W4 /WX.

Oprava v DoChangeAttrs zachová GetLastError před CloseHandle/restore, po chybě
čtení nevolá SetFileTime, po chybě zápisu/obnovy použije stávající SHOW_ERROR.
Zavření handle i pokus o obnovu Read-only zůstávají na všech těchto cestách.
Chyba otevření se uloží před obnovou atributů, aby ji cleanup nepřepsal.
Prioritu má původní chyba, restore error se použije jen bez předchozí chyby.
Žádné změny oprávnění, registrů nebo bezpečnostních kontrol Windows.
