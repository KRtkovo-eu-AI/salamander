## Akceptace

Ověřená hranice S00: `SafeFileRead`/`SafeFileWrite` silent Skip assignment,
Retry disposition `OPEN_EXISTING`, `SafeFileCreate` DupStr failure vrací
`INVALID_HANDLE_VALUE` a `ERROR_NOT_ENOUGH_MEMORY`. Bez SDK/scanner závislosti.
Celý donorový harness vyžaduje budoucí `SafeFileRootLength` (S03): S01 použije
ASCII `RoundTrip`/`InjectRead`/`InjectWrite`/`FailDuplicate` s minimální adaptací.
Donor nepokrývá všechny Write Skip/Read+Write Skip All scénáře; doplnit je.

Vynucená chyba zápisu a Retry zachovají dosavadní data i offset. Ověřit Read/Write Skip, Skip All a error return; zachovat flags a sharing.
