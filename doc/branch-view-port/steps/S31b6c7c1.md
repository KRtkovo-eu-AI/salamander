## Implementation and provenance

Both bundled UnpackWholeArchive wrappers reject delete-requested plus NULL output
with ERROR_INVALID_PARAMETER before engine work. ZIP retains its discovery, actual
QuickSortArcVolumes and exact dedup, but every archiveVolumes->Add return is checked.
Failure reports existing localized IDS_LOWMEM and returns FALSE, so an incomplete
handoff does not authorize the host volume loop.7Zip no longer adds its single
input before extraction. It hands off only after the existing result calculation,
client/progress/CanCloseArchive and directory cleanup, checks Add, and returns the
existing localized IDS_INSUFFICIENT_MEMORY failure. Removed one unused local scalar
delTempDir, with no behavior change. No new strings or dialogs were introduced.

Adapted existing wrappers by Open Salamander Authors, Milan Kase and Samandarin
Contributors from the pinned donor, GPL-2.0-or-later. Actual ZIP sort is reused
unchanged in the native harness. Existing plugin/Igor Pavlov7-Zip/vendor notices
are preserved. No public SDK/vtable/layout, host deletion guard or vendor source
changed. No parallel API/framework or dependency was added.
