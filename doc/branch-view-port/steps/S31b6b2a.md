# S31b6b2a — společná interní definice identity diskového cíle

Parent86367e632158cc7ad22420679ccb581ccd03086f. První předem naplánovaný
předkrok S31b6b2, nikoli dokončená kontrola životnosti při extrakci.

CFilesActionDiskTarget je přesunutý z fileswn8.cpp do interního
fileactiondisktarget.h. Celá definice včetně hodnot, signatur, maskového
resolveru a pořadí live-registry/getter kontrol je po normalizaci EOL shodná.
Fileswn8 i fileswn7 zahrnují jedinou definici, host vcxproj/filters ji evidují.
Není nový obecný framework ani veřejné SDK; header vyžaduje známé interní
mainwnd/fileswnd/widepath typy. CFileData/PluginData/virtual ABI se nemění.

Native generátor čte skutečnou definici z nové hlavičky. Všech448 assertions
v disk_target_identity_tests.cpp.in zachováno byte-ekvivalentně po EOL;
placement assertions zůstaly, navíc se kontrolují oba include vstupy.
Žádné nové Directory Capture ani target admission v této etapě. FilesAction
control flow a UnpackZIPArchive i ostatní fileswn7 funkce beze změny.

## Nutný navazující rozsah

S31b6b2b musí zavést adresářový default, který nepřebírá root\*.* maskový
kontrakt. Validovat implicitní existující root, tab/type/generation, živý registr
před dereference a modal/create/dispatch hranice; zvlášť ověřit dialogovou
historii, manuální cíl, switch/closed/inactive/detached cíle v D/R.
CPluginData::UnpackArchive volá InitDLL uvnitř dispatch vrstvy před plugin
UnpackArchive. Pouhý check v controlleru před PackUncompress tedy nesmí být
vydáván za post-InitDLL ochranu. Nejmenší interní propojení a jeho actual
callback testy je nutné vyřešit současně, nikoli obejít inicializaci či změnit
vlastníka soukromého listingu. Před implementací zapsat přesnou akceptaci.
Source lifetime a přímé Unpack jsou nadále oddělené otevřené části.

Celá S31b6b2, G04/G05 i S31 OPEN; Branch admission zachovaný, ChangeDir a
long-source GUI odložené, S32 se nezahajuje. Tento commit pouze připravuje
znovupoužití ověřeného kódu bez jeho duplikace.
