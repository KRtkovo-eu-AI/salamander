## Implementace

Interní host CPluginData::UnpackWholeArchive má dva volitelné poslední parametry
const CFilesActionDiskTarget* sourceSnapshot a diskTarget, oba default NULL.
InitDLL zachovává původní pořadí a failure návrat. Ihned po úspěšném InitDLL
se sourceSnapshot.Panel porovná s operation source panel a oba supplied snapshots
se validují přes existující IsCurrent(MainWindow). Invalidace vrací FALSE a
ERROR_RETRY před konstrukcí CSalamanderForOperations a SDK callbackem.

IsCurrent je nezměněný sdílený live-tab resolver: nejdřív FindLive v attached a
detached registry, teprve poté čte panel identity/getters. Ověřuje TabId, disk
kind, scanning, exact wide root, Branch flag/generation a původní visible side.
Vlastní Root/DefaultPath jsou owned, raw pointer není důkaz živého panelu.
Source routing navíc nedovolí použít platný snapshot pro jiný operation context.
Header forward deklarace už existovala, nepřidává se nový generický framework.

Mění se pouze concrete host deklarace/implementace, nikoli SDK virtual nebo
PluginIfaceForArchiver.UnpackWholeArchive signatura. SDK callback nadále dostane
stejné archive/mask/target/delete/volumes parametry. Nullable default zachovává
dosavadní ordinary callers v ExecuteUnpacker beze změny; v c4a tento dispatcher
ani controller nové snapshots ještě nepředává. Nelze tedy tvrdit, že běžné GUI
už má novou runtime lifecycle ochranu. Je to kompilačně a nativně ověřená
nezbytná integrační příprava; c4b/c musí dodat backend binding a controller.
