vstupem, po CheckPath, po edit-save callbacku, před tag/property writes a před

virtuální panel odmítá diskové API a adresáře se jako dosud needitují.

tokenů %s/%d/%08X/%%; vložené hodnoty se znovu neinterpretují jako formát.
Lokalizované char texty UTF8-first/ACP, filename bez ACP roundtrip/truncation.
CTruncatedString.SetW a CMessageBox zachovají celé jméno, důvod i HRESULT,
včetně dark scheme; GetFileAttributesW při chybě používá extended exact cestu.
Číselný HRESULT scratch není cestový buffer. Žádná nová veřejná SDK metoda.
CM_EDITPROPERTIES se povolí až s těmito guards, všechny dosavadní příkazy a
bezpečnostní kontroly zůstávají. third_party.md/REUSE.tsv doplněné, GPL/SPDX
Open Salamander Authors/Samandarin Contributors zachované.
