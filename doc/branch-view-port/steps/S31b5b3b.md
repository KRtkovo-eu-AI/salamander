# S31b5b3b — přesná caller kapacita split path/mask/newDirs

## Implementace a ABI

Interní consts.h deklarace SalSplitWindowsPath a SalSplitGeneralPath mají povinné
pathBufSize; General navíc newDirsBufSize. Nejsou to SDK virtual metody.
FilesAction a PluginFSFilesAction předávají skutečnou kapacitu svých SAL_MAX_PATH
bufferů. CSalamanderGeneral v zip.cpp zachovává přesně původní public signatury,
ale free funkcím předá minima slíbená SDK: path2*MAX_PATH a newDirsMAX_PATH.
Public spl_gen.h i plugins.h a jejich vtable/metody nejsou změněny. Demo/wmobile
klienti skutečně používají newDirs[MAX_PATH]; větší buffer nelze ze staré ABI
poznat. Nad těmito garantovanými kapacitami SDK metoda explicitně odmítne případ,
nevrací zkrácený prefix. Není to nové dlouhé/wide pluginové rozhraní.

Vstup je NUL-ověřen v udané kapacitě a dosavadním SAL_MAX_PATH byte limitu;
split pozice se kontrolují v rozsahu vstupu před dereferencí. General kontroluje
místo pro oddělovací NUL, backslash + universal mask a relativní newDirs ještě
před mutací/creation dialogem. Rename-to-same-name obnoví dočasný separator i při
nedostatku prostoru. Chybová unsupported-file větev má pro volitelný backslash
skutečnou caller kapacitu. Error je stávající lokalizovaná hláška, žádné tiché
truncation ani nová anglická UI věta.

Windows adapter vlastní heap mezikrok (nejvýše SAL_MAX_PATH+8), protože General
formát je o backslash větší než konečný Windows formát. Při nedostatku paměti
vrátí stávající low-memory hlášení před zápisem. Po odstranění redundantního
slash ověří konečnou directory-NUL-mask-NUL délku ještě před CreateDirectory.
Do caller path kopíruje až úspěšný výsledek a přebazuje mask pointer; chyba/cancel
ponechá caller input nedotčený a mask=NULL. Drive-root mask se nekompaktuje;
preflight její caller kapacity předchází i multi-item warningu. Scope není
filesystem transakce: selhání skutečné tvorby může jako dříve ponechat již
vytvořené adresáře a ohlásí jejich existující parent (oprava S31b5b3a zachována).

Žádná změna Windows zabezpečení/registrů, SDK ABI, Branch entry guardu ani
odloženého ChangeDir. Výchozí LongPathsEnabled zůstal0.
