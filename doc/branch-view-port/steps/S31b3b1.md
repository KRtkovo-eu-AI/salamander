## Důvod a rozsah

Donor i target již obsahují wide ReadFileTagsW, WriteFileTagsW,
WriteFileStringVectorPropertyW, ReadFilePropertyTextW, WriteFilePropertyTextW,
IsFilePropertyWritableW a InitFilePropertyValueFromText v salamdr4.cpp.

vstup je zatím odmítnut. Existující Branch property tests ověřují hlavně čtení
sloupců; neprokazují skutečný zápis, clear ani readonly/unsupported chyby.

Produkční kód, command policy, SDK a Windows nastavení beze změny.

## Test

Nový branch_edit_properties_io_tests.py extrahuje a kompiluje devět skutečných
funkcí z hostu (včetně TrimFileTag/ContainsFileTag). C++ fixture používá reálné
SHGetPropertyStoreFromParsingName, GPS_READWRITE, property capabilities,
SetValue a Commit. Žádné COM, filesystem, property nebo GUI facades/stubs.
JPEG2x2 vytvoří skutečný WIC encoder; do pixelů ani fixtures nezasahuje donor
binary. Cleanup pouze vlastní unique temp root, výsledek kontrolovaný.

Šest reálných cest: ASCII, Unicode/emoji basename, ASCII basename v Unicode
rodiči, více Unicode rodičů se stejným basename,100 CJK znaků v basename
(UTF8 byte-long), a plná cesta307–308 UTF16. Root a další control JPEG mají
stejné jméno same.jpg; nesprávné root+basename by tedy nebylo tiché NOT_FOUND.
Každý zdroj: Unicode Keywords+Title write/read/clear, přesné tagy/pořadí a Title,
WIC dekódované pixely shodné před/po a nevybraný sentinel byte-for-byte shodný.
Metadata přirozeně mění JPEG bytes; netvrdíme byte-identitu upravených zdrojů.

Read-only fixture: skutečný write vrací0x80030005/STG_E_ACCESSDENIED,
capability0, bytes beze změny; vlastní atribut následně obnoven.
Unsupported.txt: write0x80004005/E_FAIL, capability0, bytesABC nedotčené.
Missing file se nevytvoří, invalid/null argumenty odmítnuté, read výstupy vyčištěné.
