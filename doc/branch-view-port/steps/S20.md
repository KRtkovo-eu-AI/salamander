# S20 — Panelové operace a dočasný výběr

Stav: PLANNED. Rozsah, závislosti a PR hranice jsou návrh z promptu; před převzetím je nutné ověřit je úzkým diffem připnutého donoru a skutečným target kódem. Jména testů níže jsou převzata ze zadání, nikoli potvrzení jejich dostupnosti nebo běhu. Zdrojový prompt: `steps/S20-panel-operations.md` v balíčku určeném v [SOURCE.json](../SOURCE.json).

## Rozsah

Převzít skutečný tok cesty z panelu přes dialog do existujících workerů pro rename, copy/move a delete. Běžný panel vrací správné dosavadní cesty; zachovat virtual/disk rozlišení.

## Plánované předpoklady

S04/S05/S17 a potřebné worker hranice S19. Každá podetapa ověří vlastní skutečně zavedené předpoklady.

## Donor a testy

Konkrétní audit připnutých symbolů a mezer: [BOUNDARIES.md](../BOUNDARIES.md).
Úplný seznam donorových souborů této etapy a sdílených hunks: řádky S20 v
[REUSE.tsv](../REUSE.tsv). Tyto zjištěné hranice upřesňují původní prompt.

- Zdroj: Donorové panel operation call sites a panel_temporary_selection.h.
- Testy: panel_temporary_selection_tests a příslušné donorové operation kontrakty/I/O; F2/F5/F6/Shift+Delete Cancel smoke.

## Akceptace

Cancel odebere pouze dočasné označení správné položky, explicitní uživatelský výběr zachová. Unicode/long paths, přesné cíle operací a nedotčené zdroje; mixed-parent harness bez veřejného Branch UI.

## Plánované podetapy

- S20a — Rename + dočasný výběr: F2, Cancel a zachování explicitní selection; panel_temporary_selection_tests.
- S20b — Copy/move: F5/F6 a odpovídající dialog-to-worker path tok, skutečný výsledek a Cancel.
- S20c — Delete: Shift+Delete, přesná identita položek a Cancel bez nechtěného zásahu.

## Validační brána a PR hranice

Před kódovým commitem: Windows Debug i Release x64 (host, změněné komponenty a tranzitivní závislosti), relevantní native testy a skutečný smoke běžného panelu/operace; společné SDK/hlavičky vyžadují všechny podporované konzumenty. Příkazy a přesnou evidenci SHA/runtime určuje [VALIDATION.md](../VALIDATION.md). Publikační checkpoint navíc vyžaduje čistou podporovanou sestavu a povinnou platformní matici. Nedostupná native/GUI kontrola není PASS; další etapu nezačínat.

Tři samostatné hranice S20a rename+selection, S20b copy/move a S20c delete. Každý běh jediná podetapa a koherentní commit; název podle dokončené operace.

V jednom běhu provést jen jednu nejmenší dokončitelnou etapu/podetapu. Dodržet [CONTRACT.md](../CONTRACT.md), aktualizovat REUSE/PROGRESS a evidenci testů; převzatý kód i testy evidovat vůči připnutému DONOR_SHA. Tento dokument neposkytuje oprávnění k push/PR/merge.
