## Co se přebírá

Ze zdroje src/plugins/filecomp/filecomp.cpp se přebírají celé helpery
GetFileCompPanelItemPath, FileCompPanelItemNamesEqual a příslušná migrace
CPluginInterfaceForMenu::ExecuteMenuItem. precomp.h a vcxproj přidávají
existující S05 spl_diskselection.h. Všechny tři výsledné produkční Git bloby
jsou shodné s připnutým donorem; nedochází k plošnému importu souborů.
Dialogový cleanup z předkroku zůstává v dialogs.cpp/.h beze změny.

Příkaz zachytí potřebné selected/focused/source/target snapshots a dále
nepoužívá živé CFileData řádky. Vstupy, metadata i přesné wide názvy vlastní
snapshot. Dva source výběry si drží pořadí, selected+distinct focused
nezamění identitu a jednoznačný target se hledá podle skutečného NameW.
Více shodných target basenames znamená prázdný druhý vstup, nikoli odhad.
Zachovává se chování prázdného dialogu pro nepodporovaný výběr/adresáře.
Inzerovaná neplatná služba/chyba capture operaci zastaví bez náhradního
root+basename odhadu. Běžný fallback existujícího SDK je určen pouze pro
kompatibilní Samandarin QueryService ABI; netvrdíme kompatibilitu se starým
binárním Open Salamanderem bez tohoto ABI.

Dva UTF8 buffery na haldě mají skutečnou kapacitu SAL_MAX_PATH. Helper
vyprázdní výstup a vrátí explicitní chybu, pokud převod není možný nebo
celá cesta překročí kapacitu. CFilecompThread kopíruje vstupy do vlastních
std::string Path1/Path2 již v konstruktoru, před Create a zánikem snapshots.
Nothrow alokace s úzkou obnovou debug new makra a bad_alloc chyba zachovány.
SDK interfaces/CFileData layout, engine, UI zdroje, skenování a Branch gate
se nemění. Smíšené rodiče jsou v této etapě ověřeny native harness, nikoli
ručním Branch View, který zůstává vypnutý.
