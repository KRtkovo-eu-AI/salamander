## Konkrétní mezera a adaptace

Actual donor dialogs3.cpp:CUnpackDialog používá combo index přímo pro živý
UnpackerConfig. Target zachoval tento postup: EnableDelArcCheckbox neověřoval
index proti live count, Transfer po modal přepsal Preferred index bez ověření,
zda stále odpovídá zobrazené volbě. Odebrání položky může znamenat čtení mimo
array, reorder nebo edit volbu zaměnit. Donor nemá odpovídající bezpečný helper;
jde o doloženou lokální lifecycle adaptaci, nikoli nový generic framework.

Dialog nyní drží private vector CUnpackerChoice s owned Title/Extensions a
type/OldType. Pro external volbu owns Command/Arguments a oba SupportLongNames/
NeedANSIListFile flags; pro plugin live pointer/DLLName/SupportCustomUnpack.
Combo se plní z owned titles, nespoléhá na borrowed config strings. Capture
připraví lokální vector a publikuje jej až celý; invalid metadata/config/plugin,
legacy/unknown type nebo bad_alloc odmítne. Plugin index -(Type+1) je bezpečný
i pro INT_MIN, live registry Get ověří meze. CB_ADDSTRING failure vyčistí mapping
i combo. Public SDK a plugin/vendor sources se nemění.

IsUnpackerChoiceCurrent nejprve ověří index proti owned size a live config count,
teprve pak config getters/metadata. Pro plugin ověří současný Plugins.Get a
pointer equality před dereferencí DLL/support; DLL spelling case-only změna
zůstává platná. U external kontroluje i command/args/flags. Stejné metadata se
stejným backendem znamenají stejnou sémantickou volbu; nejde o row allocation
generation ani plugin lease. Nechrání libovolné callbacky po skončení dialogu.

Checkbox používá stejnou validaci; stale/externí volba jej vypne. FromWindow
nejdřív validuje úplnou Unicode target cestu a potom vybranou volbu. Stale volba
vrací transfer error IDC_PACKER s lokalizovaným Windows ERROR_RETRY diagnostickým
textem a existing IDS_ERRORUNPACK titulkem; cesta/maska/Preferred/delete flag se
nepřepíšou. Missing backend control také necommitne částečný stav. Allocation/
combo failure má lokalizovaný ERROR_NOT_ENOUGH_MEMORY text. No-selection CB_ERR
zachovává původní Preferred=-1 smlouvu; unchanged external stále dovoluje ordinary
transfer a vypne mazání. Žádná nová cesta k externímu spuštění nebo Branch operaci.

## Native a regrese

Registrovaný unpack_dialog_path_tests používá actual constructor, celou
CUnpackDialog deklaraci, Capture/IsCurrent/Transfer/checkbox a wide conversions,
real private Unicode HWND controls. Config getter/registry/metadata a CTransferInfo
jsou explicitní doubles. SendMessage facade pouze injektuje jednorázový
CB_ERRSPACE, ostatní zprávy předává skutečnému Win32 controlu. Neprovádí I/O ani
nespouští externí programy. MSVC /W4 /WX Debug i Release99checks/0failures.

Původní main/assertions pro path případy jsou zachované přesně, přibylo jen
DataToWindow setup pro druhý bounded dialog, který nyní musí mít captured choices.
Audit porovnává přesný původní main prefix po odečtení tohoto setup. Nezměněné
ASCII/Unicode/emoji, byte-long a Win32-long, invalid surrogate/overflow/red-zone
assertions nejsou oslabeny. Nové scénáře: remove/shrink/reorder/type/title/ext/
OldType, plugin remove/replacement/DLL/null/support; external command/args/flags,
case-only DLL, unchanged external; owned-copy OOM, combo failure, missing control.
Celý caller state při odmítnutí zůstává zachován.

Počáteční OOM probe selhal timeout40s, protože Debug std::string před ověřovanou
funkcí alokoval iterator proxy a injekce vyvolala výjimku příliš brzy. Diagnostická
in-memory instrumentace lokalizovala místo před Capture. Probe byl zaměřen na
konkrétní owned title copy uvnitř Capture try/catch, kde má testovat OOM. Nepřidává
se globální potlačení výjimek ani obcházení produkčního selhání. Během úprav byl
také opraven přechodný generated compile error (lokální choices deklarace při
změně atomic capture). Jen finální99checks běhy se uvádějí jako PASS. Diagnostic
skripty zůstávají mimo Git; žádné assertion nebyly kvůli těmto problémům odstraněny.

Negativní kontrola v izolovaném generated source vypne pouze FromWindow choice
validation. Actual native99checks/28semantic failures, expected rejection;
produkce na disku beze změny. D/R původní backend133 a whole-post-init119 znovu
PASS beze změny zdrojů. Operations20/transition28 PASS, runner beze změny.
