# S31b5b3d1 — diskové kopírování do Branch cíle

Dosavadní blanket guard pro Branch target nahrazen úzkou private politikou
CFilesActionDiskTarget::AllowsBranchCopy. Dovolí právě atCopy, countSizeMode0,
copyToSelectedDirs FALSE, source i target ptDisk. Původní source Branch guard
zůstává stejný. Nejde o aktivaci archivů, plugin FS ani Move do Branch cíle.
Main command dispatcher pro disk již vede do FilesAction; nebylo nutné měnit
command allowlist ani enablers. Pinned donor blanket guard nemá; tato místní
postupná aktivace zachovává rozpracované ověřovací hranice portu.

Žádná další změna FilesAction toku: reálný owned root/default mask/tab/generation,
registry-before-dereference, atomický Unicode dialog, rozlišení implicitní hodnoty
a explicitního zadání, parsed preflight před split/create, packed kontrola i
modal/script-build/start rechecks jsou beze změny proti S31b5b3c2. Používají se
stávající per-item wide source identities a worker. Žádná nová SDK virtual metoda,
změna vtable, změna CFileData layoutu, zabezpečení nebo registrů.
