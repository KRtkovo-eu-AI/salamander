## Změna

PackGetVerifiedBranchUnpacker zachovává ptZIPArchive, Contains, nonNULL přesný
metadata interface, archive path a skutečného listing ownera. Dosavadní bundled
zip\zip.spl rozšiřuje pouze o bundled7zip\7zip.spl s Windows case-insensitive
porovnáním. Přípona ani association není náhrada skutečného vlastníka. Umístění
other\7zip.spl není kvalifikované. Nemění se ordinary dispatcher ani plugin SDK.

CPluginData::UnpackArchive před InitDLL zachytí kvalifikaci a kind ZIP/7-Zip.
Po InitDLL znovu ověří current target, DirectoryDefault/exact root text, live
owner/metadata/archive/this binding a stejný backend kind. Přepnutí mezi oběma
povolenými DLL na stejném objektu se nesmí dostat k plugin I/O; jejich private
metadata nejsou zaměnitelná. Invalidace vrací ERROR_RETRY před operation context.
První pokus odmítat nekvalifikovaný owner ještě před InitDLL porušil původní
test pořadí; byl nahrazen zachycením stavu a odmítnutím po InitDLL. Původní
assertions InitCalls a odmítnutí zůstaly beze změny; původní selhání je v evidenci.

Controller změnil pouze vysvětlující komentář. Gate dále odmítá source Branch,
deleteOp, virtuální/unknown/external target/backend a ručně přepsaný Branch root.
Snapshot ani tento guard není filesystémová transakce nebo source lifetime fix.
Žádná změna bezpečnostních kontrol Windows, práv, registrů, SDK nebo vendor kódu.
