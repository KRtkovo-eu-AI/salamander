## Skutečné GUI, export a nezávislé hashe

Čtyři vlastní hosty spuštěny s privátní kopií reg-file konfigurace, English,
produktovým schématem Windows Dark Mode (experimental). Samotná aplikace
i wide Save dialog byly tmavé. Uživatelská nainstalovaná instance se neměnila.
GUI ovládáno Computer Use, žádné CLI nenahradilo Calculate/Save/Verify.

Vlastní kořen S08-937f79fc02004580ab67f5e4e808e418 obsahuje osm zdrojových
případů pod inputs: ASCII, Unicode basename, dvě Unicode adresářové komponenty,
85-CJK adresář (UTF8 bytes>260, UTF16<260), tři 90znakové adresáře (UTF16>260),
100-CJK basename (304 UTF8 bytes) a dva same.bin v různých Unicode rodičích
s rozdílnými obsahy. Dále vlastní sentinel, negativní manifest a 512MiB soubor
pro Stop. Create-Fixtures.py zaznamenal SHA256, rozměry cest a nezávislé
zlib CRC32 + hashlib MD5/SHA1/SHA256/SHA512 všech osmi zdrojů. 55 dřívějších
fixtures ověřeno před zahájením i při každé kontrole výsledků.

Celkem 80 skutečných Calculate digestů nezávisle porovnáno, 32 manifest
entries ověřeno bez ořezání jmen/cest a se správnými hashi; 32 pozitivních

z exportního souboru a skutečného čtení/hash/Verify, nikoli z oříznutého UIA
názvu. Netvrdí se nezkrácený accessibility text všech dlouhých řádků.

Verify-Fixtures.py porovnává přesné cesty, SHA256 všech 11 vlastních + 55
starších originálů a celý inventář vlastního kořene. Jen čtyři očekávané

ukončeny, žádný nový report, Debug/Release configstorage.ini obnoveny bajtově.

k parentu a runtime patchi. Velký cancellation fixture zůstává vlastním test
zdrojem; žádná uživatelská data nebyla použita.

Limity: mixed-parent panel scénář a dlouhá cesta samotného manifestu jsou
native fixture; veřejné Branch UI se nespouštělo. GUI prokázalo dlouhé zdroje

Testovaný Stop je skutečné přerušení aktivního Calculate; nejde jen o zavření
již dokončeného dialogu. Žádná GUI chyba produktu nebyla zjištěna.
