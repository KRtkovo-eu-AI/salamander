Stav: PLANNED. Rozsah, závislosti a PR hranice jsou návrh z promptu; před převzetím je nutné ověřit je úzkým diffem připnutého donoru a skutečným target kódem. ## Rozsah

Převzít společnou sides/context vrstvu s dynamickými UTF-8 full paths z wide snapshotů; zachovat JSON schema, native ItemInfo ABI a skutečné limity payloadu.

- Testy: Donorové testy dlouhých CJK basename, escaping, limitů a úplnosti JSON; přesné názvy prompt neuvádí. Skutečné runtime testy oddělit od source-contract kontrol.

## Akceptace

Audit S00 nalezl v donorovém diffu tři Salamatrix soubory, ale žádný nový
specifický test dlouhého CJK JSON payloadu. Existující source contracts nejsou
důkaz tohoto I/O. V S11 doplnit nejmenší relevantní payload regression test
pro úplné JSON a limity; uvést jej jako adaptační test s doloženou mezerou.

Parita všech pěti runtime providerů, kompletní JSON a explicitní limity bez ztráty cesty. Společnou vrstvu znovu použít; bez potřeby nepřepisovat všech pět providerů.
