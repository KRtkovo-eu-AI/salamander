## Převzetí a funkční smlouvy

Donor `47661e92d4b3cbe5bb593ae3d75a3f1f698ef413`. Úzký diff pouze

viditelný credit v doc/third_party.md; mapování v [REUSE.tsv](../REUSE.tsv).

SplitCommand zachytí focused-only owned SDK disk selection, skutečné FullPathW,
NameW a DirectoryW před dialogem. Z aktuální wide identity získá velikost.
Default source/subdir target je skutečný parent; other-panel target používá
stávající disk-only kontrolu. CombinePlan uchová vlastní seznam přesných cest:
explicitní díly neztrácejí rodiče, implicitní focused discovery omezuje
sourozence na skutečný parent, zachovává case-sensitive rodiče a odmítá
nejednoznačné case-insensitive jméno. Gap zastaví discovery. Companion BAT/CRC
se čte ze skutečného rodiče, nikoli display rootu. Dialog se seznamem ukládá
wide plné cesty, text a cíle nejsou MAX_PATH pole.

Wide CreateFile/attributes/free-space/delete a existující S03 SafeFile wide
service zajistí I/O až k souboru. Heap-backed buffers používají SAL_MAX_PATH,
UTF8-first/ACP fallback a extended path prefix. Absolute resolver normalizuje
explicitní dot components a zachová literální trailing dot/space. Chyby
resolveru nejsou nahrazeny odhadovanou cestou. Wide dialogy, message handling,
localized strings a původní darkmode zůstávají součástí pluginu.

CombineFiles ponechává všechny input read handles otevřené bez write/delete
sharing, získá volume/file IDs a odmítne output alias, hardlink či provider
bez použitelné identity ještě před create/overwrite. Otevřené zdroje chrání
i před záměnou cíle po kontrole. CSplitCBNInputFiles/CSplitCBNSafeFileScope/
CSplitCBNProgressScope uvolní zdroje i při chybě/alokační výjimce; nothrow
alokace zachovají low-memory větve a úzkou obnovu debug-new makra. Selhání
nebo Cancel odstraní nedokončený output. Snapshot není transakce filesystému.

BAT je UTF8 s chcp 65001 a DisableDelayedExpansion, procenta a metaznaky se
escapují, metadata parser je odpovídajícím způsobem dekóduje. Limity BAT
zůstávají zachovány. GUI test BAT nespouští jako shell skript; ověřuje jeho
bajty, nezávislý CRC a skutečné načtení jména při Combine.

Jediný nový adaptační kód: devítiřádková registrace do tools/run_native_tests.ps1.
Donorový driver podporuje --configuration Debug/Release/Both; runner mu
předá právě svoji konfiguraci. Všech 50 dřívějších skupin zůstalo. Žádné
host/SDK/CI či jiné pluginové změny, veřejné Branch UI zůstává vypnuté.
