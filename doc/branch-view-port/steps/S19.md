# S19 — Worker cesty a nízkoúrovňové kopírování

Stav: PLANNED. Rozsah, závislosti a PR hranice jsou návrh z promptu; před převzetím je nutné ověřit je úzkým diffem připnutého donoru a skutečným target kódem. Jména testů níže jsou převzata ze zadání, nikoli potvrzení jejich dostupnosti nebo běhu. Zdrojový prompt: `steps/S19-worker-paths.md` v balíčku určeném v [SOURCE.json](../SOURCE.json).

## Rozsah

Převzít owned wide worker cesty a nízkoúrovňové copy/retry/ADS změny použitelné bez Branch panelu. Nemigrovat současně všechny UI dialogy ani copy scheduling.

## Plánované předpoklady

S02/S03 podle skutečně používaných pomocníků. Obecné scanner helper závislosti řešit nejmenší extrakcí z donoru, nikoli importem BranchViewState.

## Donor a testy

Konkrétní audit připnutých symbolů a mezer: [BOUNDARIES.md](../BOUNDARIES.md).
Úplný seznam donorových souborů této etapy a sdílených hunks: řádky S19 v
[REUSE.tsv](../REUSE.tsv). Tyto zjištěné hranice upřesňují původní prompt.

- Zdroj: workerpath.h a donorové worker copy/retry/ADS hranice.
- Testy: worker_path_tests, worker_copy_path_tests a jejich source kontrakty; reálné disposable I/O.

## Akceptace

Access/sharing/create flags, read-only Retry, handle tracking, identity/error behavior, Unicode/long paths; ADS jen na podporovaném filesystemu. Ověřit nezměněný scheduling.

## Validační brána a PR hranice

Před kódovým commitem: Windows Debug i Release x64 (host, změněné komponenty a tranzitivní závislosti), relevantní native testy a skutečný smoke běžného panelu/operace; společné SDK/hlavičky vyžadují všechny podporované konzumenty. Příkazy a přesnou evidenci SHA/runtime určuje [VALIDATION.md](../VALIDATION.md). Publikační checkpoint navíc vyžaduje čistou podporovanou sestavu a povinnou platformní matici. Nedostupná native/GUI kontrola není PASS; další etapu nezačínat.

Samostatný worker základ: refactor(worker): own complete operation paths.

V jednom běhu provést jen jednu nejmenší dokončitelnou etapu/podetapu. Dodržet [CONTRACT.md](../CONTRACT.md), aktualizovat REUSE/PROGRESS a evidenci testů; převzatý kód i testy evidovat vůči připnutému DONOR_SHA. Tento dokument neposkytuje oprávnění k push/PR/merge.
