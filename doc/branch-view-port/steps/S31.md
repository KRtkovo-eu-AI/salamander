# S31 — Audit úplnosti proti připnutému PR

Stav: PLANNED. Rozsah, závislosti a PR hranice jsou návrh z promptu; před převzetím je nutné ověřit je úzkým diffem připnutého donoru a skutečným target kódem. Jména testů níže jsou převzata ze zadání, nikoli potvrzení jejich dostupnosti nebo běhu. Zdrojový prompt: `steps/S31-parity-audit.md` v balíčku určeném v [SOURCE.json](../SOURCE.json).

## Rozsah

Nezávislý dokumentační audit donor diffu proti skutečnému portu nad TARGET_SHA. Oddělit target novinky, přesuny a adaptace; žádná produkční změna v auditním commitu.

## Plánované předpoklady

Dokončené plánované S01–S30 a vložené předkroky; přesná evidence checkpointů. Prostý donor/target tree diff při jiné base není důkaz chyby.

## Donor a testy

Konkrétní audit připnutých symbolů a mezer: [BOUNDARIES.md](../BOUNDARIES.md).
Úplný seznam donorových souborů této etapy a sdílených hunks: řádky S31 v
[REUSE.tsv](../REUSE.tsv). Tyto zjištěné hranice upřesňují původní prompt.

- Zdroj: DONOR_BASE_SHA..DONOR_SHA, port nad TARGET_SHA, REUSE.tsv; všechny donorové hunks/resources/tests/project registrations a deferred seznam.
- Testy: Audit skutečných build/native/smoke/ABI výsledků; deferred testy, pět Salamatrix providerů, engine limity, DLL/resources, skutečná conversion data a dokumentace.

## Akceptace

Každý hunk má EXACT/ADAPTED nebo explicitní zdůvodněné rozhodnutí; žádný neklasifikovaný kód či test. Binary compatibility neznamená Branch compatibility. COVERAGE.md uvádí mezery a nejmenší opravné etapy před S32.

## Validační brána a PR hranice

Jde o dokumentační audit: výsledky nesmějí být odvozeny pouze ze zelené špičky větve nebo z reportu donoru. Požadovat evidenci přesných checkpoint SHA a runtime podle [VALIDATION.md](../VALIDATION.md); chybějící nebo neúspěšná kontrola zůstává PENDING/BLOCKED. Kritická mezera či chybějící skutečná validace blokuje S32.

Dokumentační audit: docs(branch): record donor coverage and release gaps. Produkční opravy jako následné samostatné ověřené kroky; kritická mezera blokuje S32.

V jednom běhu provést jen jednu nejmenší dokončitelnou etapu/podetapu. Dodržet [CONTRACT.md](../CONTRACT.md), aktualizovat REUSE/PROGRESS a evidenci testů; převzatý kód i testy evidovat vůči připnutému DONOR_SHA. Tento dokument neposkytuje oprávnění k push/PR/merge.
