Převzít path-aware Shell/clipboard/recycle hranice a odpovídající call sites. Same-parent menu použije skutečný parent a child PIDLs; mixed-parent bezpečný host fallback.

## Akceptace

Canonical verbs, CF_HDROP/CIDA/drop effect, Unicode/long paths, Properties/Copy/Cut, trailing dots/spaces odmítnutí a správné recycle cíle. Desktop+absolute child PIDL není náhrada parent menu.

Před kódovým commitem: Windows Debug i Release x64 (host, změněné komponenty a tranzitivní závislosti), relevantní native testy a skutečný smoke běžného panelu/operace; společné SDK/hlavičky vyžadují všechny podporované konzumenty.
