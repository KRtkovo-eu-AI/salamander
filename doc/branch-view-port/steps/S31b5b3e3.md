## Hranice a návaznost

Zavřený připojený cíl je GUI ověřen pro Copy, přepnutý viditelný cíl pro Move
v e2. Pozitivní odpojený cíl pro Copy i Move zde. Zavření již odpojeného cíle
uprostřed operace, ABA recyklace a multithread fault injection zde nemají GUI
důkaz; native facade ověřuje obě zavřené registry větve bez getter přístupů.
Nejde o úplnou kartézskou GUI matici ani OS memory safety důkaz. Síť, cross-volume,
celá čistá supported plugin sestava, remote CI/CodeQL zde NOT_RUN. Nativní kontrola
nerozšiřuje SDK ABI ani nevypíná bezpečnostní chování Windows.
ChangeDir a long-source Unpack nadále DEFERRED/NOT_VERIFIED; původní WIP se nemění.
G04/G05 OPEN, celá S31 neuzavřena, S32 BLOCKED. Navazuje samostatný uzavírací
audit S31b5 vůči nálezům D01/D02/D03 a zbývajícím core/validačním hranicím.
