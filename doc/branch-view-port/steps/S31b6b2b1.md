# S31b6b2b1 — interní kontrola cíle po InitDLL

Parent 5d373e4984daba3986f5ddbaae16b068689f67db. První koherentní část předem
zapsaného rozdělení S31b6b2b. Nejde o dokončené zapojení archivního controlleru.

PackUncompress a konkrétní interní CPluginData::UnpackArchive přijímají optional
const CFilesActionDiskTarget*. Všechny tři plugin dispatch větve předávají pointer.
Po úspěšném InitDLL se znovu kontroluje živý registr a identita cíle; při nesouladu
se vrací FALSE/ERROR_RETRY ještě před CSalamanderForOperations i plugin callbackem.
InitDLL může vyvolat reentrantní callback, proto samotná kontrola před inicializací
nestačí. Sdílený snapshot je použitý beze změny. Init/backend error handling zůstává.
Žádná veřejná SDK virtual metoda ani její parametry se nemění.

Všichni současní produkční callers používají implicitní NULL a zachovávají původní
chování. Fileswn7 controller je byte-ekvivalentní parentu. Nový gate zatím chrání
jen budoucí explicitní non-NULL caller: není vydáván za aktivní ochranu celé F5
operace. External PackUniversalUncompress zůstává beze změny a tato etapa u něj
neprokazuje post-callback ochranu. Source listing lifetime je samostatná hranice.
