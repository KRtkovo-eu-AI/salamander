## Implementace

Donorový ChangeAttr handler nyní obslouží Branch CM_CHANGEATTR přes již převzaté
wide gettery/planner/worker. Local CBranchAttributeSelection vlastní root,
tab ID, generaci a úplné cesty efektivního výběru (nebo souboru pod kurzorem).
Každý řádek musí odpovídat aktuálnímu cache. Snapshot se porovnává po dialogu
plus CheckPath, před i po BuildScriptMain a před rušením výběru po progress
startu. Cleanup dočasného výběru nezasáhne změněný tab/listing/selection.
Při změně identity se operace neprovede; nejde o výběr podle basename.

Basic Archive/Read-only/Hidden/System a časové položky používají stávající
lokalizovaný dialog a worker. Fast compress/encrypt příkazy stále odmítnuté;
v Branch dialogu jsou NTFS controls disabled/indeterminate a ponechají hodnoty
beze změny. Je to dočasný checkpoint před S31b3a4, nikoli přijaté finální omezení
portu. Ordinary handler zůstává funkčně původní, včetně NTFS voleb. SDK/vtable,
registry, Windows security ani public experiment gate se nemění. Žádná nová UI
resource/string; existující dialog má ověřený dark/light vzhled.
