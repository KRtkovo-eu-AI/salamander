# S31b6b2b2 — diskový adresářový cíl archivního rozbalování

Parent 4dcfdbda0272d5e8c03bac7c8024ad1a8df860d6. Předem vymezený navazující
controller krok po společném snapshotu a interním post-InitDLL guardu. Donorové
krátké mezivrstvy byly opravené již v S31b6b1; nyní se zapojuje cílová životnost.

## Implementace a rozsah

CFilesActionDiskTarget::Capture dostává interní optional directoryDefault=FALSE.
Původní maskové volání i jeho význam root\*.* zůstávají. TRUE zachová přesný
UTF8 adresář bez masky a vlastní wide root, tab ID, Branch generation a informaci,
zda byl cíl při capture viditelný. IsCurrent a jeho live-registry-first pořadí
jsou beze změny. MatchesParsedDirectoryDefault vyžaduje Windows/existing-directory
interpretaci, přesný default text a secondPart na jeho terminátoru. Chybějící root,
file/root záměna nebo archive/FS reinterpretace se odmítnou před create.
Adresářový režim nemůže použít maskový parsed/split kontrakt ani naopak.

UnpackZIPArchive copy větev ověří členství targetu v živém registru před prvním
target getterem; diskový snapshot vzniká před UpdateDefaultDir a dalšími callbacky.
Default se čte z owned Root. Kontroly probíhají před dialogem, po IDOK i UpdateWindow,
po ParsePath, po create-confirmation, před každým create a před backendem. Po InitDLL
použije plugin wrapper gate ze S31b6b2b1; controller již skutečně předává non-NULL
pointer. Po backendu se obnoví priorita a ověří cíl před clear selection. Změněný
cíl vrací uživateli ERROR_RETRY1237. Po úspěšném backendu se jeho výstup nemaže jen
proto, že se cíl změnil; po neúspěchu zůstává původní cleanup. Při stale cíli během
create se uklidí jen vlastní nově vytvořený prázdný strom a odešle notifikace.

Exact nezměněný default se klasifikuje před normalizací. Jiný manual/history text
zachová resolver význam; snapshot přesto hlídá původní cílový panel po celý pokus,
stejně jako u diskového Copy/Move. Explicit drop s target=NULL zůstává bez požadavku
na protější panel a bez snapshotu. Alias/case-normalizace není důvodem k přijetí
nejistého implicitního rootu. Snapshot je kontrola panelové identity, nikoli
filesystem transakce nebo ochrana proti všem změnám souborů na disku.

Branch admission guardy zůstávají. Celý archive delete body, fileswn8 Copy/Move,
post-InitDLL wrapper, listing-owner dispatcher a veřejné SDK beze změny. Virtuální
archive/FS cílové pipeline nejsou touto etapou nově životnostně opravené. External
unpacker nezískává post-InitDLL garanci plugin wrapperu; před/po diskovém backendu
má controller kontroly, ale reentrantní external callback před I/O zde neověřený.
Source listing/selection lifetime je samostatná otevřená hranice.

## Actual GUI Debug dark a Release light

Vlastní ZIP-only private regfile profily, každá konfigurace má vlastní fixture.
ZIP DLL+english.slg reuse ze S31b6b1 přes S31b6b2b1, oba SHA256 ověřené. ZIP source
a SDK source beze změny; žádný nový ZIP build ani přimíchaný donor runtime.

1. Ordinary same.zip listing -> payload.txt F5 do protějšího target-東京 defaultu;
   následně ručně zadaný manual-東京. Oba adresáře přesný payload, sentinel zachován.
2. Při novém default F5 dialogu vlastní target adresář přesunut CLI pod ověřeným
   fixture rootem na dočasné sousední jméno. Po potvrzení actual Copy Error1237,
   žádná create nabídka ani obnovený root. Jeho nepřítomnost ověřena před vrácením
   původního vlastního adresáře; readback zdrojů i předchozích výstupů PASS.
3. Zdrojový ZIP tab duplikován a odpojen přes tab menu. Druhý pravý diskový tab
   otevře vlastní inactive adresář. Chooser explicitně vybere právě viditelný cíl,
   Remember target vypnuté. Během Copy dialogu v hlavním okně přepnuto na původní
   target-東京. Po potvrzení skutečná chyba1237, žádný inactive výstup.
4. Nový F5 vybere stejný nyní neaktivní inactive tab: úspěch, přesný output readback.
5. Další F5 zvolí tento tab; během Copy dialogu se zavře jeho cílová záložka (nikoli
   data). Po potvrzení actual Copy Error1237, předchozí výstupy a zdroje shodné.
6. Nová vlastní cílová záložka otevře detached a je odpojena. V chooseru pozorován
   stav Detached, zvolen tento cíl, default přesně detached. Po F5 success exact
   payload a sentinel. Obě konfigurace mají právě čtyři očekávané výstupy, other
   adresář jen sentinel. Všechny zdrojové SHA256 po všech scénářích shodné.
