## Boundary and provenance

Scoped donor OpenBranchItemDirectory/declaration/menu/dispatch is adapted for
current-row cache identity, missing/non-directory preflight with wide extended
paths, and owned exact wide focus after ordinary navigation replaces old rows.
The trial demonstrated two target limitations: ChangePathToDisk truncates the
UTF8 suggested focus through MAX_PATH, and CommonRefresh compares legacy Name
only. The final adapter avoids that narrow focus parameter and matches NameW
in the resulting file list. No changes to those generic navigation functions.
The preflight handles an already absent parent; it is not a filesystem
transaction or rollback guarantee for a later disappearance/permission race.

Existing S18 ViewFile/EditFile exact-path callers and S18b enumeration/service
remain in place. Remove only their S26 direct block; require current cache-row
identity before obtaining the selected file path. A temporary first-matching-mask
guard allows only core internal/configured external viewers before ViewFileInt;
plugin viewers cannot execute their callbacks or fall through after a matching
plugin mask. Explicit handler dialogs/plugin command ranges remain blocked.
Enable only CM_VIEW/CM_ALTVIEW/CM_EDIT/CM_BRANCH_OPENPARENT in the transition gate.

The exact process-only opt-in remains SAMANDARIN_EXPERIMENTAL_BRANCH_VIEW=1,
default off. Rename/copy/move/delete/packing/Shell file clipboard/drop and other
plugins remain blocked. No new resources/translations, SDK/layout/vtable changes,
workflow changes, history/tab integration or auto-refresh activation.
