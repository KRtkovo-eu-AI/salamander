## Konkrétní blokace a původ

Debug x64 host z TARGET_SHA při startu hlásí z `C__Handles::CheckClose`
(`src/common/handles.cpp:864`) volání `DeleteObject` z
`CIconList::ReplaceIcon` (`src/iconlist.cpp:483/485`), handle nenalezen.
`GetIconInfo(hConvertedIcon, &convertedInfo)` vzniklé bitmapy nezapisuje do
trackeru. Zkontrolovat i `CopyImage`, `DestroyIcon`, druhé `GetIconInfo` a BAIL
cleanup stejné funkce; nepředpokládat, že dva zachycené dialogy jsou úplný seznam.
Připnutý donor má totožný `iconlist.cpp`; žádná oprava se z něj nepřenáší.

## Nejmenší rozsah

Reprodukovat baseline, sjednotit evidenci vlastnictví a uvolnění těchto GDI
objektů podle existujících tracker pravidel. Nepřidávat obecný framework,
neměnit veřejné SDK ani široce vypínat `HANDLES`. Explicitní raw Win32 cleanup
je případně přípustný jen pro prokazatelně netrackované API objekty; zdůvodnit
volbu proti existujícímu `HANDLES_ADD_EX` mechanismu. Žádné hunks S01/S02.
Do mapy zapsat nový adaptační kód a důvod až se skutečnou implementací.
