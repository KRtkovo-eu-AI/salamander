Open Samandarin: Dialog Boxes: Configuration

History

Specify if recently used values (history) should be stored in the registry as a part of Open Samandarin and plugins configuration.

Dialog Box Options

Use colored icons in the working directory list
Uses yellow stars for Hot Paths and assigned tab colors for visits from other tabs in the List of Working Directories. A Hot Path from another tab has a small star on the tab icon. Turn this option off to use neutral colors.
Save history
When checked, recently used values (history) will be stored in the registry as a part of Open Samandarin and plugins configuration.
Save List of Working Directories
When checked, both the shared List of Working Directories and each tab's list are saved in the Open Samandarin configuration.
Save Navigated Directories
When checked, the Back and Forward navigation history of panels and tabs will be stored in the configuration and restored after restarting Open Samandarin. The history is stored separately for each panel/tab or shared according to the selected history scope. Plugin filesystem entries are restored when the corresponding filesystem can be reopened.
Share history between panels/tabs
Shows a single list of working directories shared by both panels and all of their tabs. The shared list can include visits from tabs that are now closed.
Keep history per panel/tab
Shows the working directory list of the active panel tab. Switching between the two options preserves the entries and their order in each list.
Enable Command line history
When checked, recently used commands from the Command Line will be kept in Command line history (you can access them using the button with down arrow on the right side of the Command line). If your commands contain passwords or other sensitive data, it's recommended to turn this option off.
Save Command line history
Has sense only if Enable Command line history box is checked. When checked, Command line history will be stored in the registry as a part of Open Samandarin configuration.
Clear History...
Clears all history related data from memory. If you want to clear them also from the registry (configuration), you need to save configuration after using this command.
