Open Salamander: Dialog Boxes: Configuration

Drives

Specifies how Open Salamander reads icons, catches refresh events, and obtains free-space information for removable and network drives.

Dialog Box Options

Use automatic refresh
When checked, refresh of panel depends on change notifications from Windows. Otherwise refreshing of panel will be forced after each panel operation and main window activation (when you return from other application). Monitoring of change notifications is overall better option.
Use simple icons
When checked, only the simple symbols instead of default icons provided by the system will be shown in the panels. This is useful for slow-speed media such as floppy disks, where obtaining default icons can slow down browsing.
Network drives: Use automatic refresh
When checked, panels are refreshed when they receive change notifications from Windows (you will see all changes on network drive made from other computer). But always they are also refreshed after each panel operation and main window activation (this can be suppressed, see next option). This is because some network drives (e.g. Samba on Linux, unfortunately it's not possible to distinguish it from common Windows network drive) do not send change notifications properly, so panel contents were not updated properly.
Network drives: Do not refresh on activation of Salamander
When checked, network drives are not refreshed on main window activation (when you return from other application). On some network drives (e.g. Samba on Linux) you will have to refresh panel content manually if you turn on this option.
Free-space information: Removable drives / Network drives
Choose independently whether to show free space for removable drives and mapped network drives in the Change Drive menu (Alt+F1 / Alt+F2) and Drive Bar tooltips. The information reports the space available to the current user, including disk quotas. Here, removable means drives that Windows classifies as removable media; USB disks classified as fixed drives retain their existing behavior.
  • Do not query (default): no additional free-space probes are made for this kind of drive.
  • Query once per session: when the information is first needed, query the drive in the background and keep the result for the session. The free-space column is subdued, and the tooltip identifies the value as cached and shows the date and time of the last successful query.
  • Keep updated: display a cached result immediately and refresh it in the background when it is no longer current. Opening the Change Drive menu or requesting a Drive Bar tooltip can trigger a refresh; requests are rate-limited. During a refresh, the last known value remains visible but is subdued and identified as stale.

Enabling these options can wake removable media and generate disk or network I/O. Probes run in the background with limited concurrency, so they do not delay startup, opening the menu, or displaying a tooltip. A disconnected network mapping is not restored just to obtain free space. A failed or unavailable probe shows no error dialog; the value stays empty, or a previous result remains marked as stale.

Hover over the free-space value in the Change Drive menu (Alt+F1 / Alt+F2) to see the same cached/stale status and date and time of the last successful query as in the Drive Bar tooltip. The tooltip applies only to the free-space column; clicking the drive continues to select it normally. Media and mapping changes invalidate the previous result so that a different device or share does not inherit another drive's free-space value. These settings do not change the existing fixed-drive, RAM-disk, or Directory Line free-space behavior.
