Open Samandarin: Dialog Boxes

Open Samandarin Task List

Use this dialog to break or terminate a not-responding Open Samandarin task.

Dialog Box Options

List of running Open Samandarin tasks
Contains a list of all Open Samandarin tasks. Current task has "current process" appendix.
Highlight
Flash main window of selected Open Samandarin task.
Break
Breaks selected Open Samandarin task and invokes its Bug Report dialog.
Terminate
Terminates selected Open Samandarin task.
Refresh
Refresh list of running Open Samandarin tasks
