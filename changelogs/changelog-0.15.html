Open Salamander: Samandarin 0.15 changelist

This document lists the user-visible changes made between 5.0-samandarin-0.14 and 5.0-samandarin-0.15. It does not repeat features introduced in earlier releases.

File management and storage

  • Added mounted-volume display controls and optional path/label presentation.
  • Added storage-aware scheduling for concurrent Copy and Move operations, allowing independent storage devices to transfer concurrently while conflicting operations remain serialized.
  • Fixed UTF-8 USB directory enumeration.
  • Fixed ZIP filename diacritics when Windows uses UTF-8 as the active system code page.
  • Fixed file icons to better match Windows Explorer associations.
  • Made file tooltips more compact.
  • Fixed detached-tab transitions and enabled file operations in detached tab windows.
  • Fixed a regression in tabs and Tree View.
  • Improved sorting in search results.
  • Allowed Ctrl+PgDown to open archives by content regardless of their file extension.
  • Made Registry Search abortable and prevented Find from crashing when opened.

Interface, panels, and shutdown

  • Added detachable panel tab windows.
  • Fixed main-window dragging and the initial tab-tooltip DPI font.
  • Fixed shell icons and startup-panel rendering.
  • Improved Explorer property columns and shared WebView viewers.
  • Added plug-in and extension columns to the Sort By menu.
  • Polished configurable UI fonts and viewer rendering.
  • Preserved curly-braced placeholders in the Markdown viewer.
  • Fixed viewer encoding, UI font scaling, and panel quick search.
  • Preserved the main-window size after the computer wakes from sleep.
  • Showed progress throughout application shutdown.

Viewers, previews, and rendering

  • Added native WebView viewers and extended system diagnostics.
  • Fixed Prism text-view CSS and Internal Viewer flickering.
  • Fixed File Compare whitespace glyphs and Database Viewer DPI fonts.
  • Restored PictView native decoders and the STL Explorer preview.

Salamatrix, plug-ins, and extensions

  • Added Salamatrix Studio.
  • Completed and stabilized Salamatrix Framework v1.
  • Added Process Explorer and extended Salamatrix file systems.
  • Added a hierarchical Hardware Monitor file-system extension.
  • Fixed the plug-in manager and extension behavior.
  • Fixed plug-in and extension name casing.
  • Fixed ambiguous plug-in version formatting and related plug-in version display issues.
  • Fixed the Python demo file-system listing.
  • Prevented the Python demo UI from appearing during lifecycle activation.
  • Fixed the SFTP plug-in dialog when the password is empty.
  • Made the Local Llama configuration dialog's Close button dismiss the dialog.
  • Updated Samandarin domains.

Startup, lifecycle, and build automation

  • Deferred menu-preview disposal until after the Closed event.
  • Showed extension startup progress.
  • Fixed PR test reporting after reruns.
  • Unblocked the skipped PR Test Report and queued CodeQL skips.
  • Applied additional bulk improvements across the application.

Security and package trust

  • Hardened plug-in installation trust and added the Plugin Manager security disclosure.

For the complete list of pull requests, see the GitHub comparison between 0.14 and 0.15.
