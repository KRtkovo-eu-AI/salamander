Open Salamander: Plugins: PictView: Appendix

Supported File Formats

PictView advertises a viewer or thumbnail mask only when a decoder is actually present: a built-in Windows Imaging Component (WIC) codec, a native PictView decoder, a WIC codec installed on this computer, or a Windows Explorer IThumbnailProvider / IExtractImage handler (excluding documents, archives, executables, and media). Historical extensions that are not implemented again are not listed here.

Built-in WIC formats

  • BMP, DIB, RLE - Windows bitmap
  • GIF - including animation
  • ICO - Windows icons
  • JPEG - JPG, JPE, JPEG, JFIF, and aliases JFF, JIF, THM, THUMB (content sniff)
  • PNG
  • TIFF - TIF, TIFF
  • JPEG XR / HD Photo - JXR, WDP
  • DDS - DirectDraw/DXGI surfaces: uncompressed RGBA, DXT1/3/5, ATI1/ATI2, and DX10 BC1/BC2/BC3/BC4/BC5 plus common 32-bit UNORM formats. Cubemaps, BC7, and other DXGI formats are not decoded natively.

Native PictView decoders

  • ANI - Windows animated cursor
  • CUR - Windows cursor
  • DCX - multi-page PCX
  • DTX - DirectDraw texture (DDS layout)
  • EPS, EPT - Encapsulated PostScript ASCII preview, or an embedded TIFF/JPEG/BMP/PNG/WMF preview
  • AI - Adobe Illustrator: embedded raster preview, a PDF DCTDecode JPEG, or a FlateDecode RGB/gray image XObject, not the vector artwork
  • XCF - GIMP 8-bit RGB/grayscale flattened composite (uncompressed, RLE, or zlib tiles). Indexed, high-bit-depth, text, and filter layers are skipped.
  • PDN - Paint.NET PDN3 embedded PNG thumbnail only, not full-resolution layers
  • 3DM - Rhinoceros embedded preview bitmap, not the 3D model
  • DWG - AutoCAD embedded BMP/PNG/WMF/EMF preview, or an Explorer thumbnail handler when no preview is stored, not the drawing geometry
  • SKP - SketchUp ZIP thumbnail.png / preview.png when present
  • BLEND - Blender: embedded JPEG/PNG/BMP preview only
  • FLI, FLC - Autodesk Animator
  • IFF, LBM - Amiga Interchange / Interleaved Bitmap
  • MOV - QuickTime: embedded JPEG/PNG/BMP preview only
  • PCX - PC PaintBrush
  • PBM, PGM, PPM, PNM - Netpbm
  • PSD - Adobe Photoshop composite (8-bit RGB/grayscale, flattened)
  • RAS, SUN - Sun Raster
  • SGI, BW, RGB - SGI image
  • SVG - rasterized with NanoSVG (no CSS, limited text and filters)
  • TGA - Truevision Targa
  • WMF, EMF - Windows Metafile / Enhanced Metafile, rasterized with GDI
  • STL - Explorer IPreviewHandler (Microsoft 3D Viewer): rotate and zoom in the viewer, matching the Explorer preview pane. If that handler is not installed, PictView uses an Explorer thumbnail when one is registered.
  • HPI - Hemera Photo Images: embedded JPEG/PNG preview
  • CDR, CDT, CMX, WEB, XAR - Corel/Xara: embedded raster preview only
  • PSP* - Paint Shop Pro: embedded raster preview only
  • ZBR, ZMF, ZNO - Zoner: embedded raster preview only

Optional Microsoft Store WIC codecs

These formats are associated automatically when the corresponding Windows codec is installed. They are not a built-in PictView guarantee.

  • WebP - WebP Image Extension
  • Camera RAW and DNG (ARW, CR2, CRW, NEF, ORF, PEF, RAF, DNG, and others) - Raw Image Extension or a vendor codec
  • HEIF/HEIC and AVIF - HEIF Image Extensions / AV1 Video Extension

File formats that PictView can save

Save As uses the WIC encoders available on this computer. The guaranteed encoders are BMP, GIF, JPEG, PNG, and TIFF.
