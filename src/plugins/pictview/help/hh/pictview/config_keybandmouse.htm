Keyboard & Mouse

Customization of keyboard and mouse use.

Options

Page Up & Page Down keys
Specifies whether Page Up and Page Down scroll the image or open the previous or next image file. The mouse wheel has its own setting. Select one of the following options:
Option Meaning
Used for image scrolling Use Page Up and Page Down to scroll the view.
Used to access previous/next image Use Page Up and Page Down to open the previous or next image file from the panel or the Find window. See Opening Previous or Next File from Panel or Find Window for details.
Mouse wheel
Choose whether the mouse wheel scrolls the image, changes its zoom, or opens the previous or next image file. The Ctrl+mouse wheel shortcut continues to zoom the image.
Mouse Back and Forward buttons
Use the mouse Back and Forward buttons, or corresponding browser navigation keys, to open the previous or next image file.
