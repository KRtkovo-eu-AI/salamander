# Salamatrix UI Capabilities Demo

Open this folder in Visual Studio Code with Salamatrix Studio installed. The
`ui-capabilities.salamatrix-dialog.json` design is the same 463 x 236 DLU
control gallery used by the bundled runtime demo extensions. The checked-in
PowerShell file under `generated/` makes the project directly runnable as an
extension; regenerate it from the designer after changing the JSON model.
